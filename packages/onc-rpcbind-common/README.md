# @luolapeikko/onc-rpcbind-common

Common schemas and utilities for ONC RPC rpcbind implementations. Current schemas for portmapper v2, rpcbind v3, and rpcbind v4.

## Schema implementations
- `PortMapperV2` - Implementation of the portmapper v2 protocol.
- `RpcBindV3` - Implementation of the rpcbind v3 protocol.
- `RpcBindV4` - Implementation of the rpcbind v4 protocol.
- `RpcAuth` - Common schema for RPC authentication, used in rpcbind v4 and potentially in future versions.
- `RpcRequest` - Common schema for RPC requests.
- `RpcResponse` - Common schema for RPC responses.
